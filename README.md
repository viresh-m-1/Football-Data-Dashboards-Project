# Football-Data-Dashboards-Project
Personal project testing my ability with Power BI to create visuals using public football data

### Overview
- Goal: Create dashboards and visualisation to find trends and create KPIs that provide insights
- Stack: Power BI, CoPilot

### Dataset
- Source: https://www.kaggle.com/datasets/xfkzujqjvx97n/football-datasets/versions/1

### Methods
- Set-up: Power Query, import flatfile, using star schema method to connect tables
- Analysing data: DAX, charts, measures
- AI: usage to resolve errors within measures

### Dashboard examples
- A scatter chart showing a comparison of changes in goal contributions against changes in market value for a given season for selected players
![A comparison of seasonal changes goal contributions against changes in market value](https://github.com/viresh-mistry-01/Football-Data-Dashboards-Project/blob/main/images/GA%20vs%20MV%20players.png)
- Net transfers by selected clubs each season (positive value means greater number of inbound transfers than outbound)
![Net transfers by a club each season](https://github.com/viresh-mistry-01/Football-Data-Dashboards-Project/blob/main/images/Net%20Transfers.png)
  

### Challenges
- Maintaining consistent formatting and colours within charts
- Ensuring correct syntax was used for each DAX function and remedying outdated functions
